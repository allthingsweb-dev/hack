# Changelog

Versions follow [semver](https://semver.org): a major version changes a rule, submission requirement or judging criterion.

## v1.0.0 (2026-10-06)

The first at/hack template.

- The rule: projects must be open source to be judged, in a public repository under an OSI-approved license.
- Submitting: a public repository URL, the team and a one-line description.
- Judging: it works, it's useful, it's creative; a small thing that works beats a flashy demo that doesn't.
- Files: README.md, LICENSE (MIT), SUBMISSION.md, AGENTS.md, CLAUDE.md, .agents/, .coderabbit.yaml, .gitignore and this changelog.
